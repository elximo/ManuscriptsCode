# Georgia Poultry Litter

This folder contains scripts used to run analysis and generate figures for the Georgia Poultry Litter manuscript.

For manuscript resubmission purposes, i am starting with the script used to perform the permutational permanova while accounting for the study design.

## Background
The study design include a main treatment effect applied non-factorial, to 8 farms. From each farm, 5 individual samples were taken. This renders the experimental design as follows: the experimental unit becomes the Farm (n=17) while the observational unit is the farm level sample (n=85)

Due to sequencing and QC filtering, not all samples in all farms were available for downstream processing. This rendered a non-balanced design. As such, using the permute `how()` function to generate farm-level permutations become infeasible and using `adonis2()` from **vegan** library to run PERMANOVA is no longer possible to match the study design. One alternative was to run the `nested.npmanova()` from the **BiodiversityR**. However this function is very slow as it needs to call the `adonis2()` function of the vegan package. Thus we opted to reimplement the permutations from that function and adonis2 using opus 5.5 at high effort mode for code-generation. This resulted in two logs improvement over the implementation of ``nested.npmanova()``. Estimated F and sum of square are identical.

This version of the script is hard coded for the manuscript, however, a more generic universal version will soon follow once testing is completed.

## How to run

I usually import QIIME2 objects into R. These steps were also used in the SSARE Apple Orchard manuscript (written in 2022).

1. Import metadata (e.g. `read.table()`)
2. Import distance matrix Unweighted UniFrac generated by QIIME2 `read_qza()$data` from **qiime2R** library.
3. Make sure order of samples in both objects match.
4. Use whatever ordering method. This is the one I used for the distance matrix

For UnWeightedUniFrac distance matirx imported from QIIME2

 ```
  dm_matrix <- as.matrix(Qiime2_imported_dm)
  sort_matrix <- dm_matrix[order(rownames(dm_matrix)),order(colnames(dm_matrix))]
  Qiime2_imported_dm_sorted <- as.dist(sort_matrix)
  ```
For the metadata dataframe
```
  TP3_Metadata_sorted <- TP3_Metadata[order(TP3_Metadata$SampleID),]
  Backup_SampleID <- TP3_Metadata_sorted$SampleID
  TP3_Metadata_sorted <- data.frame(lapply(TP3_Metadata_sorted,as.factor))
  TP3_Metadata_sorted$SampleID <- Backup_SampleID
```
5. Make sure the order of samples in both datasets is identical

`all(attributes(TP3_16S_BetaDiv_uwunifrac_dm_sorted)$Labels == TP3_Metadata_sorted$SampleID)`

6. Run the script
`permanova.unbalanced(TP3_16S_BetaDiv_uwunifrac_dm_sorted,TP3_Metadata_sorted)`
